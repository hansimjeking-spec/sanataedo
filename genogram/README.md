# 가계도·생태도 웹앱

이 폴더가 현재 운영 중인 가계도·생태도 편집기의 본체입니다.

## 주소

- 기본 주소: `/`
- 편집기 직접 주소: `/genogram`
- 기존 사례관리 통합 업무도구: `/case-management`

## 주요 파일

- `index.html`: 화면 구조
- `app.js`: 가계도·생태도 편집, 저장, 불러오기, 문서 초안 기능
- `styles.css`: 편집기 UI와 SVG 작업판 스타일

기존 사례관리 통합 업무도구는 `case-management/`에 분리되어 있으며, 가계도 편집기 수정은 이 폴더 안에서 진행합니다.
